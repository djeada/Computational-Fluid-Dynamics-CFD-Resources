# Machine Learning on Geometry and Meshes

The pre-processing end of the CFD pipeline: learning compact representations of CAD shapes and predicting the meshes needed to simulate them.

## Table of Contents

### 1. [ML on CAD](./ml_on_cad.md)

Representing CAD geometry for learning, latent shape spaces, classification and generation of new shapes.

### 2. [ML with Meshes](./ml_with_meshes.md)

Predicting mesh sizing fields from geometry so that goal-oriented adaptation does not need an adjoint solve for every new shape.
